# Task 4 - Version-Controlled DevOps Project

## Objective

This project demonstrates Git version control best practices as part of the DevOps internship Task 4.

## Tools Used

- Git
- GitHub
- Git Bash

## Git Workflow

The project follows this branch structure:

main → dev → feature branches

Feature branches are used for individual changes. Pull Requests are used to merge completed features into the development branch and eventually into the main branch.
